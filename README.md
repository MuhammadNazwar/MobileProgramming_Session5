## Deskripsi Project
<p align="justify">
Praktikum ini merupakan kegiatan pengembangan aplikasi permainan Tic Tac Toe menggunakan framework React Native dan Expo dengan memanfaatkan VSCodium sebagai lingkungan pengembangan. Dalam praktikum ini, mahasiswa mempelajari penerapan konsep pemrograman Front End pada aplikasi mobile melalui pembuatan permainan interaktif yang memungkinkan dua pemain bergantian menempatkan simbol X dan O pada papan permainan. Pengembangan aplikasi mencakup implementasi komponen antarmuka, pengelolaan state, logika permainan, serta penentuan kondisi kemenangan dan hasil seri. Pengerjaan praktikum mengikuti instruksi dan ketentuan yang terdapat dalam dokumen TugasTTC.pdf.
</p>
